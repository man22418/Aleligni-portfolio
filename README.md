Aleligni Kindihun - Personal Portfolio Website

About the Project

This is my personal portfolio website developed as an individual academic project for the Internet Programming I course.

The website presents my personal profile, education, technical skills, projects, and contact information.

Live Website

"Visit My Portfolio" (https://man22418.github.io/Aleligni-portfolio/)

Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

Website Features

- Responsive navigation menu
- Personal introduction section
- About Me section
- Technical skills with progress bars
- Project showcase
- Education information
- Downloadable CV
- Contact form with JavaScript validation
- Dark and light mode toggle
- Mobile-friendly design
